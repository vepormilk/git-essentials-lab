# Running the library demo

Prerequisites: Git 2.23+, JDK 17+ (java and javac), and Python 3.9+.

From the repository root, run:

```text
python3 run.py demo
```

The command compiles and runs the Java library demo, showing catalog search, book borrowing, loan receipts, and returns. On Windows, `py -3 run.py demo` is an alternative Python launcher command.
